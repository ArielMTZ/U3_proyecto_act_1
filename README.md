# MyProyectoDevOps

Proyecto de práctica para aprender la estructura de un repositorio con enfoque DevOps.

## Estructura

- `backend/` – Lógica del servidor / API
- `frontend/` – Interfaz de usuario
- `database/` – Scripts y modelos de base de datos
- `docs/` – Documentación
- `images/` – Recursos gráficos
- `.github/workflows/` – Automatizaciones (CI/CD) con GitHub Actions
